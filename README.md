## 📌 Sobre

Sou estudante de TI, com estudo contínuo em Análise e Desenvolvimento de Sistemas. Tenho interesse em desenvolvimento de software, análise de processos e gestão de projetos de tecnologia, além de estudos complementares em hardware e algoritmos.

Este portfólio reúne meus principais projetos, documentação de processos (BPMN) e informações de contato.

## 🚀 Projetos em destaque (e futuras novidades por vir 👀)

- **[Sistema de Gestão de Entregas de Móveis](https://github.com/EduardaPorcino/agendamento_moveis)** — Aplicação web para gerenciamento e acompanhamento de entregas de móveis.
- **[Sistema de Ponto Eletrônico](https://github.com/EduardaPorcino/sistema-ponto-eletronico)** — Projeto acadêmico em JavaScript para registro de entrada e saída de colaboradores.
